# 绘图样本

这份文档是 22 条回归提示词，按原文交给 Agent。前 16 条覆盖数学、计算机、AI 和办公，每个场景一条简略提示、一条详尽提示。末尾 6 条覆盖时序图、表格和分层架构。每条只要求画一张图，并已写明审查要求。新增图元时，对应领域的简略和详尽两条都要能画完。

通过看三件事：列出的对象都在；要求的关系还在；审查图里没有明显重叠、文字被裁切、箭头指错或标签挡住节点。工具返回成功表示图已经生成。提示词之外再指定对象或布局，测的就是另一条样本。

### math-matrix-long

矩阵 A 是 2 行 3 列，数字为第一行 1、2、3，第二行 4、5、6。矩阵 B 是 3 行 2 列，第一列 7、9、11，第二列 8、10、12。结果 C 是 2 行 2 列，第一行 58、64，第二行 139、154。

用颜色标出 A 的第一行、B 的第一列，以及 C 左上角的 58。在图上写出这个元素的计算：1×7 + 2×9 + 3×11 = 58。在矩阵旁边标出形状 2×3、3×2 和 2×2，并说明中间的 3 必须相等才能相乘。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- A、B、C 的每个数字都在，58 能由给出的点积复算出来。
- 高亮同时落在 A 的第一行、B 的第一列和 C 的 58 上，而不是整张矩阵都涂满。
- 形状标注可见，且没有把 B 画成 2×3。

### math-bayes-short

画一张贝叶斯公式示意图，标出先验、似然和后验。改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

### math-bayes-long

画一张贝叶斯更新图，标题写“一次检测后的信念”。

公式写明 P(H|D) = P(D|H) P(H) / P(D)。用这一组数字：患病先验 P(H) = 0.01；患病时检测为阳的似然 P(D|H) = 0.90；未患病时检测为阳 P(D|非H) = 0.05。据此写出证据 P(D) = 0.90×0.01 + 0.05×0.99 = 0.0585，后验 P(H|D) = 0.009 / 0.0585 ≈ 0.154。

图上分成四块并按这个顺序阅读：先验、似然、证据、后验。后验旁边写一句：阳性之后患病概率从 1% 升到约 15%，但仍然不大。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 四个数 0.01、0.90、0.0585、0.154 都能在图上找到，并且后验约等于 0.154 而不是 0.90。
- 阅读顺序是先验和似然进入证据，再得到后验。
- 公式里的条件方向是 H 给定 D，不是把 D 给定 H 当成后验。

### cs-binary-search-long

画一张二分查找流程图，标题写“二分查找”，从上到下阅读。

节点和分支按这个顺序：

1. 开始。
2. 处理：low、high 设为数组边界。
3. 判断：low <= high？否的话到“返回 -1”。
4. 处理：mid = (low + high) / 2。
5. 判断：a[mid] == target？是的话到“返回 mid”。
6. 否的话处理“缩小区间”，然后回到 low <= high 的判断。

判断节点的两条边分别标 yes 和 no。数组默认已经有序，不要再画一个排序步骤。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 上面 6 类节点都在，yes/no 没有标反。
- “返回 -1”只从区间耗尽离开，“返回 mid”只从相等离开。
- 缩小区间之后回到循环，而不是直接结束。

### cs-virtual-memory-long

画一张地址翻译图，标题写“虚拟地址到物理地址”，从左到右阅读。页大小按 4096 字节。

虚拟地址 0x00001234 拆成页号 0x1 和页内偏移 0x234。翻译先查 TLB。TLB 未命中时再查页表。页表项把页号 0x1 映射到物理页号 0x8A，并且该页在内存中。命中结果写明物理地址 = 0x8A000 + 0x234 = 0x8A234。

另画页号 0x2：页表项标记不在内存，箭头指向磁盘，不要给它算出物理地址。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 0x1 的路径经过 TLB 未命中后进入页表，并得到 0x8A234。
- 0x2 的路径停在缺页和磁盘，没有物理地址。
- 页内偏移在命中时被保留，没有把整个虚拟地址当成页号。

### ai-attention-long

画一层 Transformer 块，标题写“Transformer 块”，从上到下阅读。

输入 x 先做层归一化，再线性投影出 Q、K、V。注意力由 Q、K、V 计算。注意力输出与 x 残差相加。相加结果再做层归一化，然后进入前馈网络。前馈输出与进入前馈之前的表示再做一次残差相加，得到这一层的输出。

两条残差要能看出绕过了哪一段，不要把残差画成第三路独立输入。Q、K、V 都来自同一次归一化之后的 x，不要画成三个互不相关的外部输入。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 顺序是归一化、Q/K/V、注意力、残差、归一化、前馈、残差。
- 两条残差的起点和终点能对上各自绕过的子层。
- Q、K、V 标成来自 x，而不是三个没有来源的方块。

### ai-training-long

不要把验证停止画成每一批都必停，也不要省略标签。

通过标准：
