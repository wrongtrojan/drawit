# 绘图样本

这份文档是 16 条代表样本。每条标题与 `examples/` 下的工程文件名相同，例如 `math-matrix` 对应 `examples/math-matrix.drawit.json`。覆盖数学、计算机、AI 和办公，以及类、ER、状态、泳道、数轴、里程碑、树、图和长文本。张量形状放在多头注意力里。复杂过程图用颜色区分角色。

每条只要求画一张图，并已写明审查要求。通过看三件事：列出的对象都在；要求的关系还在；审查图里没有明显重叠、文字被裁切、箭头指错或标签挡住节点。工具返回成功表示图已经生成。提示词之外再指定对象或布局，测的就是另一条样本。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

### math-bayes

画一张贝叶斯更新图，标题写“一次检测后的信念”。

公式写明 P(H|D) = P(D|H) P(H) / P(D)。用这一组数字：患病先验 P(H) = 0.01；患病时检测为阳的似然 P(D|H) = 0.90；未患病时检测为阳 P(D|非H) = 0.05。据此写出证据 P(D) = 0.90×0.01 + 0.05×0.99 = 0.0585，后验 P(H|D) = 0.009 / 0.0585 ≈ 0.154。

图上分成四块并按这个顺序阅读：先验、似然、证据、后验。后验旁边写一句：阳性之后患病概率从 1% 升到约 15%，但仍然不大。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 四个数 0.01、0.90、0.0585、0.154 都能在图上找到，并且后验约等于 0.154 而不是 0.90。
- 阅读顺序是先验和似然进入证据，再得到后验。
- 公式里的条件方向是 H 给定 D，不是把 D 给定 H 当成后验。

画一张二分查找流程图，标题写“二分查找”，从上到下阅读。

- 缩小区间之后回到循环，而不是直接结束。

### cs-virtual-memory

画一张页表，标题写“虚拟地址到物理地址”。页大小按 4096 字节。

虚拟地址 0x00001234 拆成页号 0x1 和页内偏移 0x234。页表中 0x1 在内存，物理页号 0x8A，并写出物理地址 = 0x8A000 + 0x234 = 0x8A234。0x2 标记缺页，标注指向这一行，说明不能计算物理地址，并指向磁盘。缺页说明使用一格能够换行的长文本。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- 长文本留在单元格内，没有明显裁切。

## AI

### ai-mha

画一张多头注意力内部过程图，标题写“多头注意力”。

输入张量 x 的形状是 [B, T, d]。它线性投影出 Q、K、V，形状都是 [B, H, T, d_k]。用四种填充色区分 Q、K、V 和最终输出，不要混用。只展开两个头，每个头放在自己的容器里，并注明 H 可以更多。每个头里画出 QK^T / sqrt(d_k)、softmax，再乘 V，得到该头输出。两个头输出拼接成 [B, T, H·d_k]，然后做输出投影，得到 [B, T, d]。分数矩阵只高亮参与示意的格子，不要涂满。因果掩码用一条标注说明，不画成第三路输入。图上写出 softmax(QK^T / sqrt(d_k)) V。

改完调用审查，用图上的 id 做局部修改，不要因为工具成功就认为画面已经合格。

通过标准：

- Q、K、V、输出是四种填充色，且没有把查询涂成键或值。
- 两个头各自在容器中，不能合成一个方块；缩放因子可见。
- 拼接在输出投影之前。
- 高亮只落在分数矩阵的对应格，不涂满整张矩阵。
- 形状包括 [B, T, d]、[B, H, T, d_k] 和 [B, T, H·d_k]。
