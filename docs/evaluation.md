# 本轮演进与验收

2026-10-14：稳定性、系统保存、学术绘图三条主线已实现。远端 main 的 `b063306` 已合并到 `codex/evaluation-repair`，保留 16 条代表样本、工程删除和查询/键/值/输出颜色预设。历史演进目录已按远端整理，不恢复被删除的 evolution.md。

## 空白窗口证据与结论

原 Windows 安装版在连续绘制「多头注意力计算过程」时，客户区只剩页面底色 `#e7ebf0`，工具栏、画布和状态栏消失。WebView2 渲染进程、会话和已保存工程仍在；再次启动的新窗口可以显示工程，旧窗口仍空白。整棵 React 树因渲染错误卸载是推断，现场没有堆栈证据确认根因。

原 Mac 安装版在隔离数据目录提交超过 3000 次修订，观察时仍有工具栏、画布和属性，未复现整页空白。使用者要求 Mac 无法复现就先跳过，因此不继续追查现场根因，也不标为根治。

已落实：

- 连接代际、sessionId、documentEpoch、revision 共同过滤旧更新；持续退避重连，保留画面并暂停写入；清理计时器、请求及订阅，不重放结果未知的写请求。
- 选择只在集合变化时同步；无关修订保留拖动/缩放过程。节点、画布、应用分别有错误边界；异步故障单独记录，手动恢复当前会话。
- 公式统一为 MathJax 路径 SVG，移除 foreignObject；延迟 Worker、有界缓存、任务超时终止，局部公式错误不拆掉整页。
- 单实例聚焦已有窗口。Host 仅重启桌面壳自己管理的进程，不按 PID 文件杀其他进程；最新已确认修改写入内部恢复副本，恢复后仍标未保存。
- MCP 成功/错误标记修正，diagram_get 返回完整工程；WebSocket 结构、队列、文本、深度、对象数量及输出像素有集中预算。
- 文件名拒绝 Windows 保留名、冒号/备用数据流、穿越和尾部点空格；链接文件和链接目录被拒绝；导入图片仅接受内联栅格。

故障日志为本机 ui.log：对象 id、revision、组件栈及最近操作名称，不包含会话令牌或完整工程；按大小轮转。原生 WebView 进程级终止的恢复尚未实机验证。

## 系统保存与导出

首次保存选择目录，后续直接保存；另存为重新选择。导出 SVG/PNG 每次选择目录，以上次导出目录为初始位置。取消不写外部文件，也不清除未保存状态。

Rust 文件代理产生一次性目录句柄，绑定 documentId 与 document/svg/png 用途；前端不能提交任意绝对输出路径。会话负责快照和内部恢复副本，MCP 保持数据目录限制。记忆位置写入 desktop-targets.json，重启后保留。

prepareSave/completeSave 锁定确定 revision 的快照；外部文件和内部副本都成功后才报告该版本已保存。新修订仍显示未保存。目标已有文件或身份变化时确认覆盖；临时文件替换，失败恢复，规范目录和文件身份再次核验。Unix 持有目录描述符并使用 openat/renameat；Windows 重解析点与文件占用仍须用户实机核验。

Mac 正式应用包已经验证：

- 原生目录选择框能够选择含中文和空格的目录。
- SVG 和 PNG 实际落盘，界面报告所导出的 revision 和路径。
- 取消导出显示「未写入文件」，下一次默认定位到上次目录。
- 首次保存取消后仍为未保存；首次保存成功后，再次保存直接写入记忆目录，不再弹目录选择。

外部文件变化只通知，显式重新加载才更新工程；覆盖未保存修改须由用户确认。关闭保护覆盖窗口关闭及 Cmd+Q/菜单退出，保存/导出期间暂停关闭。

## 学术绘图

默认图内字体为随包 Noto Sans SC，补充 Noto Sans 拉丁字形，普通文字保留 SVG text，导出嵌入字形子集和 OFL。MathJax 数学字形与 LaTeX 源共存。白底、细线、角色色、标题胶囊、外侧括号及标签已接入画布、SVG、PNG。

schema 增加文字角色、tone、行列标签、维度与 plain/math 单元格；属性面板与目录示例可编辑。arrangeRow 在 GUI/MCP 共用，默认 60px，主体中心对齐、同父容器、固定锚点冲突整批回滚。打开工程不自动移动。

六张图：Position Encoding、Layer Norm、矩阵乘法、Scaled Dot-Product Attention、残差块、GNN 消息传递。可编辑工程、SVG、PNG 位于 examples/academic；来源、许可及确定参数见 [academic-style.md](academic-style.md)。远端原有 16 条场景保留，矩阵乘法样本同步重绘。

视觉检查已修复公式估宽、窄说明竖排、中英混排缺字，以及矩阵重复投影继续变大造成的裁切。额外连线折点、曲线和外侧标签进入导出边界。自定义样式优先，只有缺省和精确匹配历史内建默认的样式映射到新规范；id、语义字段和 pinned 保留。

## 检查与剩余验收

既有全量回归、类型检查、前端构建、Rust 文件代理测试和随包运行时冒烟已通过。新增固定种子 1200 步操作序列验证增删改、复制、分组、撤销重做、非法事务回滚和保存往返。新增六图尺寸、公式、字体子集及导出边界回归。具体最终结果见 [validation.md](validation.md)。

生产依赖及开发依赖审计均无已知漏洞；MathJax 的 xmldom 间接依赖、Vitest/tinypool 工具链已更新到修复版。审计结果不代表不存在未知漏洞。

新 Mac 安装版长压提交超过 2000 次修订后，按使用者「无需做这么久的测试」要求提前停止，未记为完整 10000 次/30 分钟通过。后续采用短回归与实际功能验收，不再延长压力测试。

Windows 安装版由使用者在本轮修缮结束后验收。原空白窗口根因、Windows 原生文件占用/重解析点与 WebView 进程故障恢复保留待验证，不把跨平台验收写作全部通过。
