# 使用指南

这份文档说明安装版和开发版界面怎么用。把 drawit 接到 Agent 见 [mcp.md](mcp.md)。

安装版打开后会启动随包会话，不需要另装 Node。第一次启动打开二分查找示例。

## 新建、打开与保存

工具栏的加号新建图示，文件夹按钮打开文档列表。修改后状态栏显示“未保存”。点击保存按钮，或按 Ctrl/Cmd+S。切换文档前先保存当前图。文档标题在右侧修改。

工程保存在数据目录的 `documents/` 下：

- Windows：`%APPDATA%\drawit\documents`
- macOS：`~/Library/Application Support/drawit/documents`
- Linux：`$XDG_DATA_HOME/drawit/documents`，未设置时是 `~/.local/share/drawit/documents`

`DRAWIT_HOME` 可以改数据目录。改了之后，编辑器和 MCP 使用同一个目录。

工程文件是 `.drawit.json`，里面保留对象 ID 和语义字段。“文件”菜单可以导入工程，或导出 SVG、PNG。

磁盘上的工程被另外改过时，编辑器会提示。点击“保留当前内容”继续编辑当前这份。点击“重新加载”改用磁盘上的文件，当前未保存的修改会丢掉，版本号继续增加。

## 绘图与整理

点击或拖入左侧组件。组件库和分类可以折叠。选中对象后，右侧按几何、文字与内容、样式分组编辑属性。

“排列”菜单提供对齐、分布、吸附到网格和自动布局。对齐至少选两个节点，分布至少选三个。这些操作在选用对应命令时执行。勾选“固定位置”的节点，自动布局保持原位。

时序图先放生命线，再放消息和激活条，并在属性面板选择对应生命线。消息的横向端点跟随生命线，纵向位置表示时间顺序。激活条的高度表示持续时间。

表格可以逐格编辑表头和内容。合并或取消合并时，选择起始行列和跨行、跨列范围。

分层架构使用容器和有向连线。目标标注可以选择目标对象，并显示箭头。

## 语义图元

类图用“类”填写类名、属性、方法和可选构造型；ER 用实体和联系，连线标签写基数。状态图在属性里选择初始、普通或最终状态，再用带事件标签的连线表示转移。

泳道可选横向或纵向。先创建泳道，再将步骤的“所属容器或泳道”设为对应泳道，几何坐标相对父泳道。自动布局留出标题带，固定的泳道保持原位。

数轴填写标题、方向、最小值、最大值和刻度；刻度值必须在范围内。组合两条数轴时，调整位置使相同的原点相交。张量填写名字和形状。里程碑逐项填写日期和文字，按日期顺序等距展示，同日事件分别保留。

树可逐层编辑孩子，重名节点仍按各自的结构位置连接。图可编辑顶点、边和边标签。有向无环图按层次排列，循环图使用网格。

树、图、矩阵、向量、数组、栈、队列、表格及类分区会根据内容增大绘制尺寸，并在长文本处换行。宽高是最小外框，图元不会因文本编辑自动改变位置；重叠时可手动移动或明确调用布局。

## 快捷键

macOS 使用 Cmd，Windows 和 Linux 使用 Ctrl。焦点在输入框、文本域、下拉框或可编辑文本上时，这些快捷键留给输入。

| 按键 | 功能 |
| --- | --- |
| Ctrl/Cmd+Z | 撤销 |
| Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y | 重做 |
| Ctrl/Cmd+S | 保存 |
| Ctrl/Cmd+C / X / V | 复制 / 剪切 / 粘贴选中对象 |
| Ctrl/Cmd+D | 原位复制，并生成新 ID |
| Ctrl/Cmd+A | 全选 |
| Ctrl/Cmd+G | 组合 |
| Delete / Backspace | 删除 |
| 方向键 | 轻移一个网格；选中父容器时，子节点随父容器移动 |
| Ctrl/Cmd+0 | 适应画布 |
| Ctrl/Cmd+加号 / 减号 | 放大 / 缩小 |
| Esc | 取消选择 |

复制容器时包含子节点和内部连线。复制时序图对象时保留必要的生命线引用。粘贴生成新 ID，并偏移位置。系统剪贴板不可用时，编辑器仍使用自己的对象剪贴板。

## 交给 Agent

安装版在状态栏点击“复制 MCP 配置”，把得到的 JSON 放进 Cursor 或 Claude Desktop。配置指向当前系统的 drawit 程序和随包运行时，端口由应用发现。

开发版的配置、调用顺序和错误处理见 [mcp.md](mcp.md)。

## 界面恢复

会话断开后画面保留，编辑暂时暂停，程序会重新连接。超时的写操作不会自动重试；重新连接后以会话返回的工程为准。单个对象无法绘制时，可在属性中修改其内容；画布遇到错误时点击“重新加载此窗口”。这些操作不会删除会话中的工程。

再次启动 drawit 会聚焦现有窗口。故障信息保存在本机数据目录的 ui.log；无需把工程或会话令牌发送到外部服务。

## 选择保存位置

桌面版首次保存工程时选择系统目录；之后“保存”及快捷键沿用该位置。“文件 → 另存为…”可重新选择。工程文件名为文档 id 加 `.drawit.json`；标题修改不会悄悄改名。保存位置在本机记忆，数据目录仍保留同一快照的恢复副本。保存期间到达的新修改仍显示未保存。

导出 SVG 或 PNG 每次选择目录，上次导出位置作为初始目录。取消选择不写文件；目标已有文件或被外部修改时会要求确认覆盖。错误消息说明具体失败原因，不把失败记为保存成功。

外部工程变化会提示，点击重新加载才使用该内容（会丢弃当前未保存修改）。目录消失或被替换时，用另存为重新选择。浏览器开发模式仍在内部数据目录保存，并通过浏览器下载导出。
